## What this software does

LoopHaven reads the same public pages a browser reads, using your own account
when a download requires a session. It parses HTML and posts the site's public
search forms. It is a client, not a mirror:

- it performs one request at a time, at human pace;
- it does not build a copy of the catalogue;
- it does not create or use multiple accounts;
- it does not bypass download quotas, rate limits, or access restrictions.
