An unofficial Looperman API, CLI and MCP server

Looperman has no public API. LoopHaven is a local service that reads the site the way a browser does and exposes its real search filters as JSON: one HTTP API, one haven command, and an MCP server for agents. It does not redistribute audio, and it does not work around the download quota.

Last verified against the live site on 16 November 2026 · v0.1.0 · MIT

pip install "loophaven[mcp]"

# 1. start the local API
python -m uvicorn loophaven.api.app:app --host 127.0.0.1 --port 8000

# 2. search — public previews need no account
curl "http://127.0.0.1:8000/api/search?genre=Trap&bpm=140&limit=2"

What makes it different from the other scrapers

There are a dozen Looperman downloaders on GitHub. They all stop at “here is some HTML”. Three things are different here.

  • It speaks the site's own vocabulary. Genre, category, key, time signature, tempo range, date window and sort order are resolved from the advanced-search form itself, not guessed from URL slugs. Ask for F#m, Bb or 4/4 and it sends what the site actually submits.
  • It is honest about what it returns. total is null past page one, because Looperman stops counting. When the quota is hit you get a 429, not a silent MP3 renamed to .wav.
  • It plugs into a DAW and into agents. One HTTP API, one CLI, and an optional MCP server, so a ReaScript, a shell script or Claude can all ask the same questions.

What it is not

  • Not an official API. Nothing here is published or supported by Looperman. If their HTML changes, parsing breaks — that is why the reverse-engineering notes are in the repository.
  • Not a mirror. The repository ships zero audio files. Downloads use your own account and consume your own quota.
  • Not a workaround. One account per person, no rotation, no proxies. A 429 means wait.
  • Not a cloud service. It binds to 127.0.0.1 and has no authentication. Do not expose it.
